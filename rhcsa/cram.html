完整指南

Root 密碼重設 ★

GRUB 開機選單 → 按 e → 在 linux 核心列末端附加參數 → Ctrl+X

  • rd.break 方法： mount -o remount,rw /sysroot → chroot /sysroot → passwd root → touch /.autorelabel → 執行 exit 兩次退出
  • 備用方案 init=/bin/bash：remount rw / → passwd → autorelabel → exec /sbin/init
忘記 touch /.autorelabel → 重開機後 SELinux 權限錯誤導致完全無法登入！

LVM 邏輯卷管理

  • pvcreate /dev/sdb1 → vgcreate vgdata /dev/sdb1 (-s 16M 設定 PE 大小) → lvcreate -n lvdata -L 500M vgdata
  • -L = 具體容量大小；-l = 邏輯延伸區 (Extents) 數量；百分比 % 只能搭配 -l (-l 100%FREE)
  • 擴充容量：vgextend → lvextend -r -L +500M /dev/vgdata/lvdata (-r 參數會連同檔案系統一起自動調整)
  • 手動擴充檔案系統：xfs_growfs /mnt (XFS 指定掛載點) vs resize2fs /dev/… (ext4 指定裝置路徑)。注意：XFS 無法縮減 (shrink)。
  • 檢視狀態：pvs vgs lvs lsblk

磁碟分割與 Swap

  • parted /dev/sdb mklabel gpt (立即寫入生效，無法復原) → mkpart data xfs 1MiB 501MiB → set 1 lvm on
  • 格式化 mkfs 之前先執行 udevadm settle；修改正在使用中的磁碟後執行 partprobe
  • Swap 置換空間：mkswap → swapon → fstab 加入 … none swap defaults 0 0 → 執行 swapon -a && swapon --show 驗證

fstab 與掛載 ★

  • 使用 blkid 查詢 UUID → fstab 設定：UUID=… /data xfs defaults 0 0
  • 重開機前務必執行 mount -a 與 findmnt --verify 檢查
fstab 打錯字 = 系統開機進入 emergency mode = 考試整台掛掉 0 分。每次修改後務必驗證！

NFS 與 autofs 自動掛載

  • dnf install -y autofs nfs-utils; systemctl enable --now autofs
  • 主配置檔 /etc/auto.master.d/x.autofs：間接掛載 /shares /etc/auto.shares · 直接掛載 /- /etc/auto.direct
  • 對應設定：work -rw,sync serverb:/shares/work
  • 萬用字元家目錄：* -rw serverb:/home/guests/&
  • 切勿預先手動建立間接掛載目錄；修改後記得重啟 autofs 服務

SELinux 安全增強 ★

  • getenforce · setenforce 0|1 · 永久設定檔：/etc/selinux/config
  • 設定永久 Context 標準口訣： semanage fcontext -a -t httpd_sys_content_t '/web(/.*)?' → restorecon -Rv /web (正規表示式請務必加單引號)
  • 參考既有正確型別：semanage fcontext -l | grep /var/www
  • 自訂連接埠：semanage port -a -t http_port_t -p tcp 82
  • 布林值：setsebool -P httpd_can_network_connect on
  • 查看阻擋日誌：ausearch -m AVC -ts recent
  • 若找不到 semanage 指令 → 執行 dnf provides */semanage 查詢套件
使用 chcon 會在重新標籤 (relabel) 後失效！setsebool 若沒加 -P 參數在重開機後會失效！

firewalld 防火牆 ★

  • firewall-cmd --permanent --add-service=http
  • firewall-cmd --permanent --add-port=8080/tcp
  • firewall-cmd --reload · 檢查指令 --list-all
  • 保留目前執行時期的變更：--runtime-to-permanent
只加 --permanent 當前不會生效（需 reload）；沒加 --permanent 重開機就消失。兩者皆需注意！

nmcli 網路管理 ★

  • nmcli con add con-name lab type ethernet ifname enp1s0 ipv4.method manual ipv4.addresses 192.168.1.10/24 ipv4.gateway 192.168.1.1 ipv4.dns 192.168.1.1
  • 追加 DNS：nmcli con mod lab +ipv4.dns 8.8.8.8
  • 接著執行 nmcli con up lab — 修改設定後必須重新啟用連線才會套用生效
  • hostnamectl set-hostname s1.example.com 並確認 /etc/hosts
網路設定錯誤或重開機未持久化 = 評分腳本無法連入系統 = 該大項直接 0 分。

使用者與群組

  • useradd -u 2000 -G wheel,devs -s /bin/bash bob · 禁止登入：-s /sbin/nologin
  • usermod -aG devs bob — -G 若未加 -a 會覆蓋並清除原本的所有附屬群組
  • 密碼期限：chage -M 90 -m 7 -W 5 bob · 強制下次登入改密碼：chage -d 0 · 帳號過期：chage -E 日期
  • sudo 權限：在 /etc/sudoers.d/ 新增檔案 (bob ALL=(ALL) ALL)，並用 visudo -cf 檢查；或直接加入 wheel 群組：usermod -aG wheel

systemd · 日誌 (journal) · tuned

  • systemctl enable --now httpd (enable 啟用開機自啟 ≠ start 啟動！)
  • 預設目標：systemctl set-default multi-user.target · 即時切換：isolate
  • 日誌查詢：journalctl -u sshd -b · -p err · --since "…" · -f
  • 持久化儲存日誌： mkdir -p /var/log/journal && systemctl restart systemd-journald
  • 效能調校：tuned-adm active / profile virtual-guest / recommend
  • 處理程序：ps aux --sort=-%cpu · kill · nice -n 10 · renice

工作排程與時間同步

  • cron 欄位格式：分 時 日 月 週 · 0 2 * * 1-5 = 工作日凌晨 2 點 · */5 = 每 5 分鐘 · /etc/cron.d/ 系統排程需額外加上使用者欄位
  • 一次性排程：at 23:00 → 輸入指令 → Ctrl+D 結束 · 查詢/刪除：atq / atrm
  • V10 新增：使用含 OnCalendar= 的 .timer 單元 + systemctl enable --now x.timer
  • chrony 時間伺服器：在 /etc/chrony.conf 設定 server host iburst → 重啟服務 → chronyc sources -v (帶有 ^* 表示已成功同步) · timedatectl set-timezone 設定時區

dnf 與軟體套件庫 ★

  • dnf install/search/info/history · 依指令尋找所屬套件：dnf provides */semanage
  • .repo 格式 (務必背熟 — 題目只會給你 URL)：
    [baseos]
    name=BaseOS
    baseurl=http://…/BaseOS
    enabled=1
    gpgcheck=0
  • RHEL 安裝源有兩個庫：BaseOS 與 AppStream，兩個都必須設定！
  • V10 Flatpak：flatpak remote-add --if-not-exists flathub URL · install · list
  • V10 開機載入器：修改 /etc/default/grub → grub2-mkconfig -o /boot/grub2/grub.cfg · grubby --update-kernel=ALL --args=…

容器管理 (僅限 V9 考試)

  • podman pull/images/ps -a/inspect/logs · skopeo inspect docker://… · podman login · 建置映象檔：podman build -t x .
  • podman run -d --name web -p 8080:8080 -v /host:/ctr:Z IMG
  • 非 root 容器 (Rootless)：無法綁定 1024 以下的特權連接埠
  • 將容器註冊為 systemd 服務： loginctl enable-linger $USER → 進入 ~/.config/systemd/user → podman generate systemd --new --files --name web → systemctl --user daemon-reload && enable --now container-web
掛載目錄缺少 :Z = 遭遇 SELinux 權限阻擋。未啟用 linger = 使用者登出時容器服務停止。--user 必須透過真實 SSH 連線執行，不可使用 su -。

實用工具 · 權限 · Shell 腳本

  • 打包壓縮：tar -czf a.tgz /etc (z 為 gzip · j 為 bzip2 · J 為 xz) · 解壓縮 -xzf -C /dest · 列出內容 -tf
  • 搜尋：find /home -user bob -exec cp -p {} /dest \; · -perm -4000 (SUID) · -size +100M
  • 文字過濾與重新導向：grep -ivrE 'patt' /etc · 導向符號 > >> 2> &> 2>&1
  • 硬連結 ln (同一檔案系統) vs 符號連結 ln -s · SGID 群組共用目錄：chgrp devs /d; chmod 2770 /d
  • 存取控制清單 ACL：setfacl -m u:bob:rw file · 目錄預設 ACL -m d:u:bob:rw /dir · 檢視 getfacl
  • umask 計算 (從 666/777 扣除)：027 → 檔案 640 / 目錄 750
  • SSH 金鑰認證：ssh-keygen → ssh-copy-id user@host (~/.ssh 權限 700，authorized_keys 權限 600)
  • Shell 腳本基礎：#!/bin/bash · $1 $# $? · if [ -f x ]; then · for i in …; do · v=$(cmd)
